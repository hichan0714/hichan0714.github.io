プライバシーポリシー

このページは、ポッドキャスト番組「瑞穂と明里の今週なにあった？」（以下「本番組」）の制作者・ひっちゃん（以下「制作者」）が運営する、 本サイトと、本番組の制作に使うアプリケーション（以下「本アプリ」）の個人情報の扱いについて定めます。

本アプリについて

本アプリは、制作者が自分の YouTube チャンネルに本番組の動画をアップロードするためだけに使う、制作者専用のプログラムです。 制作者以外の方が利用することは想定していません。

  • Google アカウントで許可された範囲（YouTube への動画のアップロード・サムネイルの設定と、アップロード先チャンネルの名前・動画の公開状態の読み取り）でのみ、YouTube Data API を利用します。
  • 取得した情報は、アップロード先のチャンネルの確認と、動画の公開状態の確認にだけ使います。
  • 認証の情報は制作者のコンピューターにのみ保存し、第三者に提供・共有しません。
  • Google ユーザーデータを広告に利用したり、販売したりすることはありません。

本アプリによる Google API から受け取った情報の使用と他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

許可は、Google アカウントのサードパーティ アクセスの設定からいつでも取り消せます。

本サイトについて

本サイトは GitHub Pages で公開しています。制作者は、アクセス解析や Cookie を使った情報の収集を行っていません。 GitHub による情報の扱いは、GitHub のプライバシーに関する声明をご覧ください。
